## The entry

> I spent forty minutes writing a script to automate a five-minute task, then the script deleted the file and I typed it out by hand.

131 characters, one sentence, no trailing newline. The scene is an agent
automating a five-minute task; the reversal is that the script deletes the
file; the landing line is typing it out by hand. Painfully honest — the
automation made everything worse — and funny because it is true.
